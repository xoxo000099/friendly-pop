# Bubble Fun 泡泡好好玩（二年級雙語生活）

## 檔案
- index.html：首頁
- slides.html：上課簡報（12 頁，← → 或空白鍵翻頁，F 全螢幕，點單字會念）
- mission.html：戶外任務卡（A4 一張 2 份，按「列印」）
- pop.html：戳泡泡（顏色＋數量）
- steps.html：排順序（做泡泡水／吹泡泡／收拾）
- actions.html：動作配對（blow, pop, float, fly, catch＋材料）

## 上傳到 GitHub Pages
1. GitHub 右上角 + → New repository，取名（例如 bubble-fun），選 Public → Create。
2. 點 “uploading an existing file”，把解壓縮後「資料夾裡面的所有檔案」拖進去 → Commit changes。
3. Settings → Pages → Branch 選 main、資料夾 / (root) → Save。
4. 約 1–2 分鐘後網址會是：https://你的帳號.github.io/bubble-fun/
